Теория

Построение eˣ и свойства

Число e>1 получено в вопросе 13. Для рационального r=m/n, n>0, определим eʳ как положительный корень n-й степени из eᵐ. Положительные корни существуют по непрерывности и монотонности многочлена xⁿ на [0,+∞); законы степеней и рост на ℚ следуют приведением к общему знаменателю. Продолжим на ℝ формулой E(x)=sup{eʳ : r∈ℚ, r≤x}. По Архимеду это непустое ограниченное сверху множество. На рациональных x формула даёт прежнее значение.

Доказательства

Непрерывность, закон сложения и пределы

Для q=1/n имеем e1/n=1+tₙ, где tₙ>0 и e≥1+ntₙ по Бернулли. Значит tₙ→0. По определению E не убывает. Для любых x и n берём r=⌊nx⌋/n. Тогда eʳ≤E(x)≤er+1/n. Более широкая вилка er−1/n≤E(y)≤er+2/n работает при |y−x|<1/n. Ширина этой вилки стремится к нулю, поскольку eʳ ограничено, а e±1/n→1. Отсюда непрерывность. Продолжаем рациональное тождество E(r+s)=E(r)E(s) по плотности и непрерывности. Если y>x, выберем q∈ℚ между 0 и y−x. Тогда E(y)/E(x)=E(y−x)≥e^q>1. При x→+∞ E(x)→∞ по целым степеням, при x→−∞ E(x)→0 по E(−x)=1/E(x). Значит слева горизонтальная асимптота y=0, а обратная функция ln определена на (0,+∞).

Для x→+∞, n=⌊x⌋, имеем (1+1/(n+1))ⁿ≤(1+1/x)ˣ≤(1+1/n)ⁿ⁺¹. Обе границы →e (вопрос 13). При x=−y→−∞ выражение равно (1+1/(y−1))ʸ, предел снова e. Замена x=1/t даёт (1+t)1/t→e при t→0. Следствия: ln(1+t)/t→1 и (1+t)c/t→eᶜ. При x→+∞ оцениваем 0≤x/eˣ≤(n+1)/eⁿ→0 по вопросу 12. При x→−∞ дробь уходит к −∞, поскольку −x→+∞ и 1/eˣ→+∞.

Интуиция

Образ для запоминания

Малый относительный прирост порядка 1/x, повторённый примерно x раз, оставляет конечный суммарный множитель e.

Разобранный пример

Разбор. Основание и показатель меняются вместе
