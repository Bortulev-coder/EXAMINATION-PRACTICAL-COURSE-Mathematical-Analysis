База и предел по базе.

ε

хвосты, проколотая окрестность, односторонние базы

В этом вопросе

ТеорияДоказательстваИнтуицияРазобранный примерЗадачи

Теория

Определения

База на X — непустое семейство непустых подмножеств X, где для любых B₁,B₂ из базы найдётся B₃ из базы с B₃⊂B₁∩B₂. Если f:X→ℝ, то lim f=L по базе означает, что для каждого ε>0 найдётся B из базы, на котором |f(x)−L|<ε.

На вещественной области D примеры: D∩{0<|x−a|<δ}, D∩(a,a+δ), D∩(a−δ,a), D∩(R,+∞) и D∩(−∞,−R), при наличии нужной предельной точки или неограниченности в нужную сторону. Для ℕ база хвостов {n≥N} даёт предел последовательности.

Доказательства

Единственность и сравнение баз

Если L₁≠L₂, выбираем ε<|L₁−L₂|/2. База даёт непустой элемент внутри пересечения двух множеств, где одновременно выполнены взаимоисключающие оценки. Это доказывает единственность. Две базы эквивалентны, если каждый элемент каждой базы содержит элемент другой. Тогда любое условие |f−L|<ε переносится с найденного множества на более узкое из другой базы, в обе стороны.

Интуиция

Образ для запоминания

База задаёт направление приближения через набор всё более точных требований. Условие пересечения гарантирует, что любые два требования можно выполнить одновременно.

Разобранный пример

Разбор. Семейство, которое не является базой

Окрестности справа и слева от a по отдельности образуют базы. Если просто объединить эти семейства, получим два непустых множества с пустым пересечением. Двусторонняя база использует объединение левой и правой части внутри каждого элемента базы.
