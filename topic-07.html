Натуральные числа, индукция и принцип Архимеда.

∈

наименьший элемент, индуктивное множество

Теория

Определения

Здесь ℕ начинается с 1. Множество индуктивно, если содержит 1 и вместе с n содержит n+1 (для подмножеств ℝ правило применяется к каждому элементу). ℕ — пересечение всех таких множеств. Проверив базу P(1) и переход P(n)⇒P(n+1), получаем P(n) для всех n∈ℕ по определению. В сильной индукции для следующего шага можно использовать все уже пройденные случаи.

Доказательства

Упорядоченность и Архимед

Индукцией по n доказываем, что всякое непустое подмножество {1,…,n} имеет минимум: если пересечение с {1,…,n−1} непусто, берём его минимум, иначе остаётся n. Для произвольного непустого A⊂ℕ выберем n∈A и применим результат к A∩{1,…,n}. Все оставшиеся элементы больше n. Сильная индукция следует отсюда: у множества контрпримеров был бы наименьший элемент.

Если ℕ ограничено сверху, s=sup ℕ. Из точности s есть n>s−1, но n+1∈ℕ и n+1>s. Поэтому для любого x∈ℝ найдётся n>x, а для a>0 и b∈ℝ найдётся n с na>b.

Интуиция

Образ для запоминания

Индукция напоминает лестницу: база позволяет взойти на первую ступень, переход даёт возможность подняться на следующую. Архимедовость гарантирует, что одинаковыми положительными шагами можно подняться выше любой заданной высоты.

Разобранный пример

Разбор. Неравенство Бернулли

При t≥−1 имеем (1+t)ⁿ≥1+nt. База n=1. Умножаем утверждение для n на 1+t≥0: (1+t)ⁿ⁺¹≥1+(n+1)t+nt²≥1+(n+1)t.
