Теоремы Ферма, Ролля, Лагранжа и Коши.

f′

среднее значение, необходимое условие экстремума

ТеорияДоказательстваИнтуицияРазобранный примерЗадачи

Теория

Формулировки

Ферма: при локальном экстремуме во внутренней точке и существующей производной f′(c)=0. Ролль: если f непрерывна на [a,b], дифференцируема на (a,b) и f(a)=f(b), то найдётся c∈(a,b) с f′(c)=0.

Лагранж: при тех же условиях гладкости f(b)−f(a)=f′(c)(b−a). Коши: для двух таких функций [f(b)−f(a)]g′(c)=[g(b)−g(a)]f′(c). При g′≠0 на (a,b) можно записать равенство отношений, потому что Ролль исключает g(a)=g(b).

Доказательства

Доказательства

У максимума правое разностное отношение ≤0, а левое ≥0. Общий предел равен 0. Для минимума знаки наоборот. По Вейерштрассу f достигает обоих экстремумов. Если она не постоянна и значения на концах совпадают, хотя бы один экстремум внутренний, дающий Ролля по Ферма. Для постоянной f любая внутренняя точка подходит.

Вычитая из f прямую с наклоном [f(b)−f(a)]/(b−a), добиваемся равенства на концах и применяем Ролля, получаем Лагранжа. Для Коши применяем Ролля к F(x)=[g(b)−g(a)]f(x)−[f(b)−f(a)]g(x), значения F на концах одинаковы.

Интуиция

Образ для запоминания

Лагранж находит на гладкой дуге место, где касательная параллельна секущей, соединяющей её концы.

Разобранный пример

Разбор. Оценка без вычисления промежуточной точки

Для 0<a<b по Лагранжу ln b−ln a=(b−a)/c, c∈(a,b). Сравнивая 1/c с 1/b и 1/a, получаем (b−a)/b<ln b−ln a<(b−a)/a.
