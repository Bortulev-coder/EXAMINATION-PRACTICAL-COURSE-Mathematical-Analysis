Предел функции по Коши и Гейне.

lim

ε–δ, проколотая окрестность, равносильность

В этом вопросе

ТеорияДоказательстваИнтуицияРазобранный примерЗадачи

Теория

Определения и условия

Пусть a — предельная точка D⊂ℝ, функция f:D→ℝ. По Коши limx→af(x)=L, если для каждого ε>0 есть δ>0, такое что x∈D, 0<|x−a|<δ ⇒ |f(x)−L|<ε. По Гейне требуется f(xₙ)→L для любой последовательности xₙ∈D∖{a}, xₙ→a. Значение f(a) может быть произвольным или отсутствовать.

Единственность следует из несовместимости двух ε-окрестностей с непустой проколотой окрестностью a. Конечный предел даёт локальную ограниченность (берём ε=1). Если L>0, то по ε=L/2 функция положительна в достаточно малой проколотой окрестности.

Доказательства

Равносильность

Из определения Коши для заданного ε берём δ, а из xₙ→a получаем попадание в нужную окрестность при всех больших n. Обратно, отрицание критерия Коши даёт ε₀>0, при котором для δ=1/n можно выбрать xₙ с 0<|xₙ−a|<1/n, но |f(xₙ)−L|≥ε₀. Это нарушает условие Гейне.

Интуиция

Образ для запоминания

Коши требует дежурства сразу на всей окрестности. Гейне проверяет все возможные маршруты к точке, включая маршрут, составленный из нарушений.

Разобранный пример

Разбор. Локальная оценка в ε–δ форме

Для f(x)=x², a=2: |x²−4|=|x−2||x+2|. Если |x−2|<1, то |x+2|<5. Берём δ=min(1,ε/5) и получаем |f(x)−4|<ε.
